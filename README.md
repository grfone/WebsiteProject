# Personal Portfolio Website

This repository contains the source code for my personal portfolio website, which showcases my work in artificial intelligence, machine learning, computational biology, and scientific software engineering.

The website serves as a central place to present research projects, publications, technical writing, and software engineering experience.

## Features

- Responsive design for desktop and mobile devices
- Modern, minimal interface
- Project pages with detailed technical descriptions
- Publications and research portfolio
- Technical writing section
- Curriculum Vitae
- Contact information
- GitHub Pages deployment

## Technology Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Design Philosophy

The website emphasizes:

- Clarity over complexity
- Fast loading performance
- Responsive layouts
- Accessible navigation
- Professional presentation
- Readable technical content

## Local Development

Clone the repository:

```bash
git clone https://github.com/grfone/WebsiteProject.git
```

Open the `docs/` directory with your preferred editor and launch `index.html` using a local web server.

## Deployment

The website is deployed using **GitHub Pages**.

Any changes pushed to the main branch are automatically published.
